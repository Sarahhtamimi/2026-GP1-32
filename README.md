# SIAQ – Social Intelligence Alignment Quotient

## Project Overview

SIAQ is a web-based platform designed to evaluate and compare Large Language Model (LLM) responses across three dimensions: **Appropriateness, Positivity Alignment, and Socio-Cultural Values**.

The project aims to help users identify differences between LLM responses and understand how effectively each model addresses context, emotional appropriateness, and socio-cultural considerations.
## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore
- **Development Environment:** Visual Studio Code
- **Local Development Server:** Live Server
- **Version Control:** Git and GitHub

## Setup and Launch Instructions

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html` using Live Server.
5. The SIAQ website will launch in your browser.

**Note:** An internet connection is required for Firebase services.
